# MRD Reader - Releases

Windows downloads of MRD Reader. Get the latest `MRD_Reader-v*-win64.zip` from the [Releases](../../releases) page.

- Unzip it, put your own data in the `data` folder, run `MRD_Reader.exe`. Full steps are in the README inside the zip.
- The download contains no patient data and no API keys.
- Unsigned app: Windows may show "Windows protected your PC" - choose More info, then Run anyway.
